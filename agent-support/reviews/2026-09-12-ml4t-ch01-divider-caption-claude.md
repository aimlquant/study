## 1. 장 구분 페이지

### 형식 — 요구대로 바뀌었다

여섯 장 모두 같은 구조다.

```html
<h1>프로세스 규율이 중요한 이유</h1>
<p class="lead">…</p>
<div class="section-number" aria-hidden="true">1.1</div>
```

```css
.chapter-divider .section-number { font-size: 32px; color: #93bad7; position: static }
.chapter-divider > h1            { font-size: 56px; color: #f6f8fb; text-wrap: balance }
```

번호가 제목 바로 위 같은 읽기 블록에 있고, 제목이 화면의 주 요소다. 이전의 「상단 작은 제목 + 본문 거대 숫자」 배치는 사라졌다. `.section-number` 기본값(170px, 투명도 0.11 워터마크)은 구분 장 규칙이 덮어쓴다. 실제 `h1` 도 유지된다.

스킬이 금지한 형태("a small heading at the top and a lone oversized number in the body do not satisfy this format")에 해당하지 않는다.

### 접근성 — 적절하다

본문 숫자에 `aria-hidden="true"` 가 붙어 있다. 헤더의 `교재 §1.1` 이 이미 같은 좌표를 읽어 주므로 중복 낭독을 막는 처리이며, 헤더 쪽은 숨겨져 있지 않다. 시각 사용자에게는 번호가 보이고 스크린리더에는 한 번만 들린다.

### 실제 화면

| 화면 | 확인 |
|---|---|
| `final-1600-03.png` | 1.1 + 「프로세스 규율이 중요한 이유」 한 줄. 제목 우세 |
| `final-1600-19.png` | 1.3 + 「워크플로에서의 인과 추론과 생성형 AI」 한 줄. 03과 동일 리듬 |

| `candidate-390-32.png` | 모바일에서도 제목이 카드 안 최대 요소. 아래 「범위 밖」 참조 |

## 2. 그림 캡션 제거

일곱 장 전부 `figcaption` 이 없고(덱 전체 `<figcaption>` 0개), `data-deck-figure-number` 도 0개다. `main` 에 `data-caption-scope="deck" data-figure-captions="none"` 이 선언돼 있다. 실제 데이터 표 캡션 5개는 `data-deck-caption="table"` 로 남아 있어 정책과 일치한다.

### 단위·조건·해석 — 대체로 잘 옮겼다

제거된 캡션 대부분은 h1 을 짧게 되풀이하는 문구였다(「탐색과 최종 확인」, 「두 출발점과 공통 검증」 등). 잃은 정보가 없다.

의미를 담고 있던 두 장은 이렇게 처리됐다.

**슬라이드 28** — 캡션이 「원서 본문의 사후 국면별 연율 변동성」이었다. 그 단위·조건이 본문으로 이동했다.

> 원서 §1.4 본문이 보고한 1927–2024년 **사후 국면별 연율 변동성**입니다. 새 실험의 결과는 아닙니다.

`final-1600-28.png` 에서 확인했다. 이전 판의 figure-reading 은 "1927–2024년 집계입니다" 였으므로, 캡션이 갖고 있던 「사후·국면별·연율」이 실제로 본문에 흡수됐다. 모범적인 처리다.

### 보완 1 — 슬라이드 29 의 출처 귀속이 본문에서 빠졌다

캡션이 「**원서 그림의** 거시 국면별 위험 수치」였는데, 본문 어디에도 이 값이 원서 보고값이라는 말이 남지 않았다.

```text
slide-28  본문 "원서" 2회   (원서 §1.4 본문이 보고한 … / 원서 그림 범례의 …)
slide-29  본문 "원서" 0회
```

현재 슬라이드 29 에서 귀속을 담당하는 것은 헤더의 작은 좌표 `교재 §1.4 · 원서 그림 1.6` 하나뿐이다. 그 좌표는 "책의 어디에 대응하는가"로 읽히지 "이 숫자가 책이 보고한 값이다"로 읽히지 않는다. 바로 앞 슬라이드 28 이 「새 실험의 결과는 아닙니다」를 명시하는 것과 대비된다.

스킬은 캡션 제거 시 남겨야 할 것에 **attribution 을 명시**한다 — "Keep the reading guidance, evidence, units, attribution and limitations in editable slide text rather than deleting them with the caption." 28은 지켰고 29는 이 한 항목이 빠졌다.

12/15/15/16 과 15/42/53/10 은 원서 그림 1.6 의 값이지 이 덱의 계산이 아니므로, 한 구절이면 된다.

> figure-reading 첫 문장에 「원서 그림 1.6 이 보고한 값입니다」를 덧붙이거나, takeaway 를 「두 열은 별도 축이며 모두 원서 보고값입니다.…」로.

### 그림 확대 — 식별 정보가 남는다

`deck-lightbox.js` 의 라벨 결정 순서를 확인했다.

```js
if (itemTitle) return itemTitle;
if (figureTitle && figureNumber) return `그림 ${figureNumber} · ${figureTitle}`;
return figureTitle || target.getAttribute("alt") || "확대 이미지";
```

일곱 그림 모두 `data-deck-figure-title` 을 갖고 있고(값은 제거된 캡션 문구 그대로), `data-deck-figure-number` 는 없다. 따라서 확대 시 제목 줄에 번호 없이 「원서 본문의 사후 국면별 연율 변동성」처럼 표시된다. 번호를 없애면서 식별을 잃지 않았다. 폴백으로 `alt` 도 살아 있다.

## 5. 제안

`html/…/2026-09-12-ch01/assets/deck.css` 끝의 Chapter 1 전용 오버라이드 블록에 이 줄이 남아 있다.

```css

```

이 덱에는 `figcaption` 이 0개이므로 이 오버라이드는 적용 대상이 없다. **공용 템플릿 쪽 `deck-report-figure figcaption` 규칙 15개는 지워서는 안 된다** — 사용자가 번호 있는 캡션을 명시 요청했을 때의 opt-in 경로를 스킬이 규정하고 있고, 그 경로가 이 CSS 를 쓴다. 지울 수 있는 것은 회차 전용 블록의 위 한 줄뿐이며 우선순위는 낮다.

배포본 `deck.css` 와 템플릿 `deck.css` 의 차이는 19줄이고 전부 Chapter 1 전용 추가분이다. 공용 CSS 가 회차 작업으로 흐트러진 흔적은 없다.

## 한 가지 관찰 (결함 아님, 판단에 맡김)

새 lead 에서 이전의 「**이번에는** 실업률·…」이 「원서는 실업률·…」로 바뀌면서, 앞 분석과 입력이 달라진다는 **대비 표지가 빠졌다.** G1(거시 국면의 출처)의 실질은 유지된다 — 네 지표를 그대로 명시하고, 슬라이드 26 이 「원서의 **첫** 국면 분석은 …」이라고 해서 분석이 여럿임을 미리 알린다. 그래서 회귀로 보지 않는다.

다만 내용 계약의 해당 항목은 여전히 이렇게 적혀 있다.

```text
/units[16]/explanation = … 네 상태를 묶는 별도 분석임을 밝히고 최대 낙폭을 풀이한다.
```

계약은 「별도 분석임을 밝힌다」를 요구하는데 화면 문구에는 그 표지가 없다. 문구와 계약을 정확히 맞추려면 한 낱말이면 된다(예: 「원서는 **별도 분석에서** 실업률·… 보고했습니다」). 그대로 두어도 청중 이해에는 지장이 없다고 본다.
