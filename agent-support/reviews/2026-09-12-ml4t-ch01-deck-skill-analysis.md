# ML4T 1장 슬라이드 제작 스킬 분석

분석 기준: study f8a6ebde992bed5b3d49e1675ee4b1b96938ec6b, 2026-09-06.
사용자가 보고한 문제는 과도한 요약과 이해하기 어려운 발표 문장이다. 아래는 실제 지침·템플릿·코드에서 확인한 유발 요인이며, 과거 모든 슬라이드의 실패 원인을 확정한 것은 아니다.

## Codex 최초 독립 판정

Claude 판정을 읽기 전에 작성했다. 기존 스킬에는 원문 충실성, 첫 등장 용어 정의, 코드와 출력 연결, 글자를 줄이지 말고 화면을 나누라는 좋은 규칙이 이미 있다. 문제는 그 규칙보다 구체적인 템플릿 기본값과 검사가 다른 행동을 유도한다는 점이다.

| 발견 | 실제 근거 | 학습에 미치는 영향 | 보완 방향 |
|---|---|---|---|
| 장수와 절별 압축 목표가 설명 설계보다 먼저 주어진다 | deck DESIGN의 18–30장·절당 2–4장, BLUEPRINT의 “18–30장의 발표 흐름으로 압축” | 예외 허용 문장이 있어도 원리·사례를 먼저 삭제해 기본 개수에 맞추기 쉽다 | 필요한 설명 단위를 먼저 배정하고 시간은 말하기 속도·내용의 난도로 점검한다. 장수는 합격선이 아니다 |
| 범용 22장 목차가 교재 고유 논리를 대신하기 쉽다 | 기본 HTML의 CURRENT/NEW LENS, 가치·병목·도입 판단·대안 비교; “논리 순서는 유지”라는 주석 | 도입 논의가 없는 장에도 새 기술 도입 이야기를 만들고 원서 설명이 빠진다 | 기본 HTML을 복제할 레이아웃 예시로 명시하고 장별 학습 질문과 실제 리포트 앵커에서 설계한다 |

## 이번 덱의 적용 원칙

- 발행된 report.html을 내용 정본으로 고정한다. 표현을 줄여도 주장 강도, 귀속, 시간 조건과 비교 기준을 남긴다.
- 원문 6개 절과 리포트의 실습·용어·참고 자료를 연결한다. 제목만 있는 구분 장을 설명으로 세지 않는다.
- 모든 장을 같은 카드 개수나 문장 개수로 맞추지 않는다. 표, 구체적 사례, 도형, 코드와 실제 출력에 맞춰 설명을 나눈다.
- 발표자 노트가 없어도 화면의 중심 논리를 이해할 수 있어야 한다. 발표자 노트에는 말로 풀어 줄 순서와 전환을 더한다.
- 학습용 CPU 실험과 원서 장기 분석 보고값을 각 결과 화면에서 구분한다. 자료를 열어야만 알 수 있는 조건을 작은 출처에 숨기지 않는다.

구현·검증 결과와 Claude 검토 반영 여부는 이 문서에 이어 기록한다.

## 독립 검토와 반영 판단

[Claude 검토](2026-09-12-ml4t-ch01-deck-skill-claude.md)는 같은 기준선의 6개 해시를 전후 확인했고 기존 KG 8회차의 설명·코드 이월 편차를 조사했다. Codex 최초 판정 뒤에 읽었다.

- **채택:** 리포트 단독 발행 뒤 덱 파생에 필요한 그림 표시가 0개일 수 있다는 사각지대. 이번 리포트 10개 그림에 required를 부여한다. 본문 의미는 바꾸지 않고 Slides 탐색 링크와 함께 메타데이터만 보강한다.
- **채택:** “최대 세 개”는 설명의 존재나 충분성을 보장하지 않는다. 문구를 읽는 법·실제 관찰/원리·해석 경계를 화면에서 설명하도록 바꾸고, 본문과 연속 화면도 인정한다.
- **채택:** 실습의 입력·코드·실제 출력·해석을 같은 단위로 기록하고 실제 코드/차트/표와 연결하는 검사를 추가한다.
- **채택:** 범용 22장 순서 대신 정의·구체적 예·도형 해설·코드·결과의 재사용 레이아웃 예시를 제공한다. 마감 기준에도 무음 읽기와 실습 연결을 추가한다.
- **일부 채택:** “장수를 늘리는 것만으로 해결되지 않는다”에 동의한다. 장수 상한 자체가 유일한 원인이라는 주장은 하지 않는다. 다만 설명을 압축하라는 반복 문구와 절당 장수 지시는 제거해 모호함을 줄인다. 실제 설명 몫과 발표 시간을 먼저 검토한다.
- **대안 적용:** 모든 source-fidelity 리포트의 required 그림 개수를 1개 이상으로 강제하거나 figcaption span 개수를 세는 방안은 적용하지 않는다. 그림이 필요 없는 원자료나 본문에서 충분히 해설한 도형을 오판한다. 이번 회차의 필수 시각자료 선택, 제작자용 설명 대응 기록과 실제 화면 검토를 함께 사용한다.
- **추가 수정:** 자체 그림·표 번호를 리포트 번호와 혼동하던 검사를 명시적 캡션 구분으로 수정한다. 의미를 보존한 발표용 재배치가 필수 그림 커버리지로 인정되도록 기존 provenance 조건과 검사도 일치시킨다.

과거 회차를 일괄 재작성하지 않는다. 이번 ML4T 1장 덱에서 새 기준의 효과를 실제 화면으로 검증하고 공용 제작 경로만 좁게 보강한다.
