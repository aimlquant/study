### QA 하네스의 정직성 확인

요청대로 검사 wrapper가 제품의 배치나 상태를 덮어쓰지 않는지 `menu.html` 소스를 읽고 확인했습니다.

- 실제 `#settingsToggle` 을 `click()` 합니다. `is-open` 클래스를 직접 붙이지 않습니다.
- `opacity` 는 `getComputedStyle` 로 **읽기만** 합니다. 값을 주입하지 않습니다.
- `p.getAnimations().forEach(a => a.finish())` 는 CSS 전환을 끝 상태로 진행시킬 뿐이며, 그 끝 상태는 사용자가 전환 후 보는 상태와 같습니다.
  스타일을 덮어쓰는 방식이 아니고, 이후 300ms를 더 기다려 레이아웃을 안정시킵니다.
- 적합 판정은 패널과 네 링크의 실제 `getBoundingClientRect()` 를 네 변 모두에서 비교하며, 링크가 4개가 아니면 실패합니다.
