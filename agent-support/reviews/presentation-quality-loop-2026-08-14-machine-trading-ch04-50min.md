## 라운드 3 / 청중 리뷰 일괄 반영

### 리뷰에서 확정한 문제

- 첫 본문 장이 맥락 없이 `73% → −7.2%`를 던졌고, 발표 운영 과정과 상세 리포트 번호가 청중용 화면에 섞여 있었다.
- 본문 글자와 신경망 재학습·평균화 그림이 작았으며, 발표 그림을 클릭해 확대할 수 없었다.
- 배깅과 랜덤 포레스트의 차이, 분류 트리의 GDI, 시간순 검증 정확도, 편도 2bp, 단계적 회귀가 27개 중 7개에서 멈춘 이유, 63일 중첩 포지션의 정규화가 한눈에 들어오지 않았다.
- 여러 SVG의 화살표가 상자 경계와 맞지 않거나, 트리 다섯 개가 트리처럼 보이지 않았다.

### 반영 결과

1. 첫 본문 장을 `같은 회귀 트리의 CAGR — 학습 73%, 테스트 −7.2%`로 바꾸고, 같은 모형·고정 테스트라는 비교 조건과 오늘의 질문을 같은 화면에 제시했다.
2. 발표 운영 메타 문구를 제거하고, 본편과 부록 모두 청중이 독립적으로 읽을 수 있는 내용으로 정리했다.
3. 발표 그림은 본편/부록 모드별로 `그림 N`을 독립 부여하고, 상세 리포트 번호와 분리했다. 출처 검증에 필요한 값은 작은 `교재 좌표`로만 남겼다.
4. 모든 발표 그림에 클릭·Enter 확대, 휠·버튼·핀치 줌, 드래그 이동, Esc 닫기와 포커스 복귀를 연결했다.
5. 순수 배깅과 랜덤 포레스트를 `행만 바꿈` 대 `행과 노드별 변수 후보를 함께 바꿈`으로 나란히 그렸고, 트리 다섯 개를 실제 분기 구조로 교체했다. Python 별도 실험의 10.5%와 8.7%는 다양성이 수익을 보장하지 않는다는 경계와 함께 표시했다.
6. 분류 트리 첫 장에 `GDI = 1 − Σp²`와 이진 분류식 `2p(1−p)`를 풀어 쓰고, 다음 장에서 시간순 검증 정확도 52.7%가 다음 검증 구간의 방향 적중률이며 수익률이 아님을 설명했다. 2bp는 `2 basis points`, 편도 거래금액의 0.02%로 정의했다.
7. 재학습과 평균화 그림을 확대하고 표를 아래에 배치했다. 단계적 회귀는 27개 후보에서 한 개씩 추가해 일곱 번째 p=0.0499까지 통과한 뒤 다음 후보가 기준을 넘지 못해 멈추는 흐름으로 다시 그렸다.
8. 63일 전략은 발표 신호의 부호로 방향 결정 → 다음 거래 시점 진입 → 63일 유지 → 실제 열린 포지션의 총 절대 노출로 일별 손익 정규화의 네 단계로 정리했다. 분모가 63인 것은 63개 단위 포지션이 실제로 열려 있을 때뿐이라고 명시했다.
9. 사용자가 지적한 화살표뿐 아니라 같은 회차의 SVG 전체를 감사해, 끝점을 상자 좌·우·상·하단 중앙에 맞추고 화살촉 앞 샤프트가 보이도록 수정했다.
