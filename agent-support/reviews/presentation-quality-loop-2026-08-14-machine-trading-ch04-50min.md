## 합의와 반증

### 채택

1. 기본 발표를 38장으로 줄이고 17장은 `?appendix=1`에서만 여는 선택형 보충자료로 둔다. Claude의 34장 권고는 방향을 채택하되, 사용자가 특별히 요구한 분류 트리 개념·실험과 부스팅 실험을 본편에 유지해 38장으로 조정했다.
2. 단계적 회귀, 회귀 트리, 시간순 교차 검증, 배깅, 랜덤 포레스트, 부스팅, 분류 트리, SVM, HMM·EM, 신경망, 횡단면 정규화에 개념→입출력→작동 원리→실험→실패 경계가 이어지게 했다.
3. 부스팅, SPX 모식도, 63일 보유, Python 일곱 모델의 alt·캡션·aria-label을 실제 자산과 일치시켰다.
4. 63일 중첩 포지션의 자기상관과 연율 샤프 과대평가 가능성을 그림 22와 마무리에 표시했다.
5. 교재 배깅 7.2%·0.5와 Python 10.5%·0.69를 별도 근거로 분리하고, 교차 검증 0.6%·0.11을 리포트 표에 복원했다.
6. 단계적 회귀 43.6%가 공식 실행 기록의 반올림값이고 교재 인쇄값은 43.5%임을 리포트와 덱에 표시했다.
7. K 관련 확인 질문을 “큰 앙상블은 안정되지만 작은 앙상블의 수익 우위는 우연일 수 있다”는 리포트의 실제 주장으로 교정했다.
