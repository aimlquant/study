합성 자료 학습 모델과 실제 자료 학습 모델의 예측 오차 비교

효용 평가의 한 사례: 예측 모델 학습용 합성 데이터의 가치를 TSTR 오차 비율로 확인
앞 페이지의 TSTR·TRTR 비교 → 두 모델의 실제 시험 오차를 비율로 요약

ERROR RATIO

오차 비율의 정의

$$\mathrm{TSTR\text{-}error\text{-}ratio} = \frac{Error_{TSTR}}{Error_{TRTR}}$$

  • $Error_{TSTR}$: 합성 자료로 학습한 모델을 학습에 쓰지 않은 실제 시험 자료에서 평가한 오차
  • $Error_{TRTR}$: 실제 자료로 학습한 모델을 동일한 실제 시험 자료에서 평가한 기준 오차

EXAMPLE

설명용 예시: 같은 실제 시험 자료에서 측정

  • MAE(평균 절대 오차): 예측값과 실제값 차이의 절댓값을 평균한 지표
  • 실제 자료 학습 모델의 MAE: 10 = $Error_{TRTR}$
  • 합성 자료 학습 모델의 MAE: 12 = $Error_{TSTR}$
  • 비율 $12\div10=1.2$ → 예측 오차가 20% 더 큼
  • 비교 조건: 같은 모델 종류·입력 변수·예측 목표·평가 기간

비율 ≈1: 비슷한 오차 · >1: 더 큰 오차 · <1: 잡음 감소의 이점 또는 정보 누출 등 확인 필요 · 수익률 비율과 구분

01

오차 비율이 1 근처·1 초과

  • 1 근처: 실제 자료 학습 모델과 비슷한 오차
  • 1 초과: 실제 자료 학습 모델보다 큰 오차
  • 두 모델의 실제 오차 크기도 함께 확인
  • 설명용 예시: 두 모델 모두 오차가 커도 비율은 1일 수 있음
02

오차 비율이 1 미만

  • 합성 자료 학습 모델의 오차가 더 작음
  • 잡음 감소에 따른 예측 성능 개선 가능
  • 정보 누출·목표 단순화·제한적인 평가 조건도 점검
  • 설명용 예시: 시험 기간을 생성 모델 학습에 포함했다면 공정한 평가 불가

TSTR은 예측 모델 학습용 효용의 한 검사 → 전략·위험 평가 등 다른 목적에는 별도 지표 필요

참고: MAE(평균 절대 오차)는 낮을수록 좋음 · 정확도·AUC는 높을수록 좋음 → 비율의 해석 방향 구분

보호가 필요하면 생성 모델의 학습부터 설계

  • DP — Differential Privacy(차등 프라이버시): 개별 기록의 포함 여부가 공개 결과에 미치는 영향을 수학적으로 제한하는 보호 원칙
  • DP-SGD — Differentially Private Stochastic Gradient Descent(차등 프라이버시를 적용한 확률적 경사하강법): 각 기록의 학습 영향을 제한하고 잡음을 추가해 DP를 구현하는 학습 방법

ACF vs PACF

GBM: 일정한 변동성의 기본 기준선 vs 점프-확산: 불연속 움직임 추가

교재 §5.3

GBM

기하 브라운 운동(Geometric Brownian Motion, GBM)

$$dS = \mu S\,dt + \sigma S\,dW$$

  • $\mu$ 드리프트, $\sigma$ 일정한 변동성, $dW$ 브라운 운동의 무작위 증분
  • 로그 가격 증분은 가우시안, 변동성 일정 → 블랙-숄즈처럼 해석적으로 다루기 쉬움
  • 변동성 군집 없음·초과첨도 없는 얇은 꼬리 → 핵심 정형화된 사실 누락

MERTON

점프-확산(Jump-Diffusion, Merton model)

$$dS = \mu S\,dt + \sigma S\,dW + S(e^{Y}-1)\,dN$$

  • 복합 포아송 과정으로 불연속 움직임 추가 → 두꺼운 꼬리·폭락 유사 움직임을 명시적으로 생성
  • $dN$ 강도 $\lambda$의 포아송 증분, $Y\sim N(\mu_J,\sigma_J^2)$ 로그 점프 크기
  • 보통 기대 점프 기여분만큼 드리프트 조정 → 미조정 시 무조건 평균 자체가 잘못 설정될 수 있음
  • 기본형: 점프 도착과 변동성 상태가 독립 → 스트레스 국면에 점프가 모이는 실제 시장과 다름

투자 예시 — GBM: 장세가 바뀌어도 같은 변동성을 계속 적용 · 점프-확산: 평소 작은 등락을 이어 가다 특정 사건 때 가격이 한 번에 크게 하락

큰 하락 점프 추가 → 평균 수익률이 의도대로 유지되는지, 위기 때 점프가 몰리는지 확인

ORNSTEIN-UHLENBECK

평균회귀(Mean-Reversion)

$$d(\log S) = \kappa(\theta - \log S)\,dt + \sigma\,dW$$

  • 로그 가격이나 스프레드가 장기 균형으로 끌려가는 동학
  • $\kappa$ 평균으로 돌아가는 속도, $\theta$ 장기 수준, 반감기 $\ln(2)/\kappa$: 현재 편차가 절반으로 줄어드는 대표 시간
  • 스프레드·일부 금리·원자재 환경에 적합 vs 추세가 형성될 수 있는 일반 자산 수익률을 모두 설명하지는 못함

STOCHASTIC VOLATILITY

확률적 변동성(Heston)

$$dv = \kappa(\theta - v)\,dt + \xi\sqrt{v}\,dW_{v},\;\; \mathrm{Corr}(dW_S, dW_v)=\rho$$

  • 가격식 $dS=\mu S\,dt+\sqrt{v}\,S\,dW_S$, 순간 변동성 $\sqrt{v}$, $\kappa$·$\theta$ 분산의 회귀 속도·장기 수준, $\xi$ 분산 과정의 변동 크기
  • 음의 $\rho$ → 가격 하락 뒤 변동성이 높아지는 레버리지 효과, 두꺼운 꼬리·변동성 군집 생성 가능
  • 분산이 음수가 되지 않는 이산화 기법 선택 필요(전체 절단 오일러, Andersen의 QE)

MODEL

GARCH(p, q)

$$r_t=\mu+\sigma_t\varepsilon_t,\quad \sigma_t^2=\omega+\alpha(r_{t-1}-\mu)^2+\beta\sigma_{t-1}^2$$

  • 이산시간 수익률의 분산 모델링

Tail-GAN: 실제·합성 VaR·ES 차이에 대한 생성기 손실 벌점

위험 제약 생성을 위한 Tail-GAN 사용 — 교재 §5.5

LOSS

생성기 손실의 꼬리 항 (Cont et al., 2025)

$$L_{tail} = \lambda_{1} \big| VaR_{\alpha}^{real} - VaR_{\alpha}^{synth} \big| + \lambda_{2} \big| ES_{\alpha}^{real} - ES_{\alpha}^{synth} \big|$$

  • 겨냥한 문제: 표준 GAN이 평균적인 분포 충실도를 최적화 → 드물지만 중대한 꼬리 사건의 가중치 축소
  • 위험 관리: 분포 중심보다 위험가치(Value-at-Risk, VaR)·기대부족분(Expected Shortfall, ES) 같은 꼬리위험 측도의 일치가 더 중요할 수 있음
  • $\alpha$: 보통 1% 또는 5%로 정하는 꼬리 확률 / VaR: 그 꼬리 확률의 손실 경계 / ES: 그보다 나쁜 손실들의 평균
  • real·synth: 같은 꼬리 수준에서 계산한 실제·합성 표본의 VaR·ES
  • $(\lambda_1,\lambda_2)$: 꼬리 일치와 전체 분포 적합 사이의 균형
  • 포트폴리오 초점: 개별 자산이 아닌 포트폴리오 수익률에서 계산 → 실제 위험 한도가 포트폴리오 수준에 있고 자산 간 공동 의존성이 손실 확대를 결정

순서 제약에 의한 이동 순서 보존

$$S(X)^{i_1,\dots,i_k}=\int_{0<t_1<\dots<t_k<T} dX_{t_1}^{i_1}\cdots dX_{t_k}^{i_k}$$

  • $i_1,\dots,i_k$: 경로의 어느 좌표(자산)를 따라 적분하는지 표시
  • $t_1<t_2$: 앞 사건이 먼저 → 순서 제약이 이동 순서 보존
  • 수준-k 상승 → 더 복잡한 좌표 상호작용

투자 예시 — 급락 후 회복한 기록 vs 상승 후 하락한 기록: 끝 수익이 같아도 중간 손실은 다름 / 주식 ETF가 먼저 오르고 채권 ETF가 뒤따른 기록 vs 반대 순서 기록 → 서로 다른 시그니처

FORWARD

마르코프 연쇄로 가우스 잡음 추가

$$q(x_t\mid x_{t-1}) = N\big(x_t;\sqrt{\alpha_t}\,x_{t-1},(1-\alpha_t)I\big)$$

  • $\alpha_t=1-\beta_t$, $\beta_t$: 단계별 잡음 스케줄(noise schedule) / $I$: 등방성 가우스 잡음의 공분산 구조
  • $t$: 거래일이 아닌 생성 모델의 처리 단계, 단계가 충분히 많으면 $x_T$ ≈ 등방성 가우스 분포
  • 잡음 스케줄 → 단계별 신호 대 잡음비 → 복원 난도 결정

REVERSE

이전 상태의 조건부 분포 학습

$$p_\theta(x_{t-1}\mid x_t) = N\big(x_{t-1};\mu_\theta(x_t,t),\Sigma_\theta(x_t,t)\big)$$

  • $\mu_\theta$: 조건부 평균(예상 중심) / $\Sigma_\theta$: 조건부 공분산(남는 불확실성)
  • 잡음 제거기: $x_t$와 $t$의 임베딩 입력 → 두 모수 또는 잡음 $\varepsilon$처럼 동등한 양 출력
