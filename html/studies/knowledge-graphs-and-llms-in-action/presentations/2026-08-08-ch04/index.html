SECTION 4.4.1

4.4.1 LLM 기반 임상 의사결정 지원 분석 — 발견을 진료로 잇다

발견을 실행 질문으로 바꾸되 안전 게이트를 유지한다

4.4.1
AIML QuantDECISION GUIDE

다중 소스 KG + LLM은 세 조건이 맞을 때만 운영 가능하다

Chapter 4의 예제를 실무로 옮길 때는 데이터 연결성, 지표 적합성, LLM 통제성을 따로 검증한다.

GOOD SIGNAL

적합 신호

  • 공통 식별자와 온톨로지가 있다
  • 질문에 맞는 부분 그래프와 경계가 정의된다
  • LLM 해석에 원 질의와 경로 링크가 붙는다
  • 전문가 승인과 보류 선택지가 있다

WARNING SIGNAL

위험 신호

  • 코드와 이름이 섞여 중복 노드가 생긴다
  • 범용 클러스터를 도메인 사실로 읽는다
  • LLM 설명만 남고 근거 경로가 사라진다
  • 임상 안전성 검토 없이 권고로 노출한다

작은 실험 — 대표 소스 2개, 질병 3개, LLM 답변 10개로 식별자·지표·해석 게이트를 먼저 검증한다.
